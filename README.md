# Rock Paper Scissors Game – Dictionary Version 📖🎮

An improved Python implementation of Rock‑Paper‑Scissors that uses dictionaries for cleaner, more readable code.

## Features
- Play against the computer
- Randomized computer choices
- Clear win/lose/draw messages
- Uses emojis for more fun 🎉
- After a win, asks if you want to continue
- Dictionary-based logic for better readability and maintainability

## About
- Text-based simple game
- Runs in termina
